# Learnings library

Reusable patterns from winning campaigns. Updated by **meta-ads-09-learning-loop**.

Suggested files (create as you learn):

- `hooks.md` — scroll-stopping openers that worked
- `angles.md` — message angles with performance notes
- `audiences.md` — targeting clusters worth retesting
- `creative-formats.md` — static vs video, aspect ratios, styles
- `losers.md` — what to avoid (with evidence)

Each entry should cite **campaign slug**, **date**, and **metric** (CPA, ROAS, CTR) when known.
